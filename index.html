OneDrive Notice: This folder is synced with Microsoft OneDrive. Even after local deletion, copies may remain recoverable in your online cloud recycle bin or version history.

How Cryptix Protects Your Files

Cryptix uses AES to encrypt file contents, RSA to protect the AES key, and SHA-256 to verify integrity and detect unauthorized changes.

Algorithm Role Used in Encryption Used in Decryption
AES-256-GCM Confidentiality Encrypts file payload with unique 256-bit key Decrypts file content using recovered AES key
RSA-3072 OAEP Key Management Protects (encrypts) the AES key using public key Recovers the AES key using unlocked private key
SHA-256 Integrity Computes original fingerprint stored in metadata Recalculates fingerprint & compares: SAFE / TAMPERED

Change Passphrase

Your existing encrypted files will remain safe and accessible with the new passphrase.

Forgotten Passphrase

Because Cryptix uses zero-knowledge encryption, a forgotten passphrase cannot be recovered. Your encrypted files will remain permanently locked without it.

You can choose to start over with a new vault. The current vault will be renamed as a backup, but it will stay unreadable without the old passphrase.
